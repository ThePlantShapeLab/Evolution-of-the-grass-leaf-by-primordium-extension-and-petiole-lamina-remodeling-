# Evolution-of-the-grass-leaf-by-primordium-extension-and-petiole-lamina-remodeling-
Models published in the paper "Evolution of the grass leaf by primordium extension and petiole-lamina remodeling " Science 
See original manuscript and supplementary materials for a full description of the models. 

Models are created in the Growing Polarised Tissue Framework (https://sourceforge.net/projects/gftbox/files/ ) with a Matlab R2021a. 
Published models were run using rev.20210803 of the GPTFramework. 

The "Volumetric_models_of_primordium_emergence" contains the code for the models shown in the Main Text Figures 2,4, and Supplementary Figures S1,S2. These models are based on a 3D dome-shaped canvas, and the original description of the modelling framework can be found at : https://doi.org/10.1098/rsob.190057 

In the code Kpar corresponds to KOP in the paper, Kpar2 corresponds to KPD, and KPER corresponds to KPER. 
        
        * Model 1: "Ring model". A single orthoplanar polarity field with high specified growth rates perpendicular to the polarity in the primordium zone (PZ) and the apex. This model corresponds to Fig. 2C to D of the paper. 
        
        * Model 2: Abaxial mutant leaf initiation. Output of this model is shown in Fig. 4J to K of the paper. 
        
        * Model 3: Wildtype eudicot leaf initiation. Output of this model is shown in Fig. 4C to D of the paper. 
        
        * Model 4: Eudicot prs mutant leaf initiation (no MARGINAL domain). Output of this model is shown in Fig. 4E to F of the paper. 
        
        * Model 5: Eudicot prs wox1 mutant leaf initiation (no MARGINAL and no OLATERAL domains). Output of this model is shown in Fig. 4G to H of the paper. 
        
        * Model 6: Wildtype grass leaf initiation. Output of this model is shown in Fig. 2I to L of the paper. 
       
        * Model 7: Narrowsheath mutant leaf initiation.  Output of this model is shown in Fig. 2P to Q of the paper. 
       
        * Model 8: "Sloping primordium model". A single othoplanar polarity field with high specified growth rates perpendicular to the polarity in the primordium zone (PZ) and the apex. Within the PZ growth rates decline from the midpoint. This model corresponds to Fig. 2E to F.
